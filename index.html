Where this stands

Said plainly.

Built

Open-source checks for completeness, window, and truncation. Runnable today, with a published method.

Built locally

The HTTP decision API and Observe Mode wrapper are implemented and tested locally. They are not deployed or running in anyone's production path.

Not yet

No customer is blocking live orders through Nobulex. A separate gateway prototype returns permit, block, or escalate. It has no customer result. Nothing is published from the registry: every issued record is held. The main repository, arian-gogani/nobulex, returns HTTP 451 under a DMCA notice.

Questions

Short answers.

What are you actually selling?

A proposed study of one billing change. Not a deployed billing product, and not a customer result.

Is anyone running this in production?

No. The checks are open source. The gateway is local. This page will keep saying so until that changes.

Does a signature prove the amount was right?

No. A signature shows who signed a decision. It cannot turn a wrong source into a right one.

Where is this going?

Billing accuracy for usage-based products. A fixed-fee audit now, a read-only scanner for self-contradictions in design, mutation checks in CI after that, and each layer gets built only once the one before it pays. The approach, with its limits stated.
